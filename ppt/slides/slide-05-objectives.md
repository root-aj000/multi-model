# Slide 5 — Objectives

## What to Say (Speaker Notes)
"Based on the problem, I set myself **6 clear objectives** for this project. First, build a **single model** that predicts **9 attributes at the same time** — this is called multi-task learning. Second, **fuse two modalities** — visual features from a CNN and textual features from a Transformer. Third, achieve **production-grade accuracy** with proper validation, metrics, and visualizations. Fourth, expose the model through a **FastAPI REST endpoint** so other apps can use it. Fifth, build a **Next.js dashboard** so non-technical users can upload ads and see predictions. Sixth, maintain **clean architecture, tests, and documentation** so the project is maintainable. These 6 objectives guided every decision I made."
